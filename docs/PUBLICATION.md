包含全部 71 个波形 CSV、69 条有效波形的完整离线 HTML、全部现有脚本、处理表、PNG/SVG/可编辑接线图、设置笔记及手动对齐导出。论文正文和旧 Git 历史不包含在内；历史工作记录经过脱敏后保留在 `docs/history/`。

## 已做的处理

- 每个原始波形的唯一仪器序列号替换为 `REDACTED`；数值采样行与源副本逐行一致。
- 本机用户目录、实验室仪器 IP、私人文档 ID/修订 ID 和个人邮箱不进入公开文件。
- 数据目录由脚本位置推导；对齐脚本默认使用仓库内 `visualize/`；采集 IP 为必填参数。
- HTML 的来源字段使用相对目录 `.`，重新生成时也不会嵌入绝对路径。
- PNG 重新保存以去除文本/EXIF 信息，逐像素验证保持不变；保留尺寸和 DPI。
- 新仓库使用通用维护者提交身份，没有复制原 `.git`。
